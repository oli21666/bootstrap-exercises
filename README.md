# Ćwiczenia Bootstrap 5

[English version below](#bootstrap-5-exercises)

Zestaw ćwiczeń z HTML, CSS i Bootstrap 5. Strona prezentuje responsywną galerię zdjęć, nawigację z menu rozwijanym, przełączniki kategorii oraz przykładowy formularz.

## Opis repozytorium

Projekt zawiera jedną stronę HTML zbudowaną z wykorzystaniem lokalnej kopii Bootstrap 5.0.2. Układ galerii zmienia się w zależności od szerokości ekranu, a nawigacja zwija się na mniejszych ekranach. Nawigacja i formularz bazują na zadaniach z egzaminów zawodowych INF.04. Strona zawiera również wyszukiwarkę i przełączniki kategorii. Elementy te są przykładami interfejsu — nie są połączone z logiką aplikacji.

## Ćwiczenia

| Plik | Opis |
| --- | --- |
| `index.html` | Responsywna galeria 12 zdjęć, nawigacja z menu rozwijanym, wyszukiwarka, przełączniki kategorii i przykładowy formularz. |
| `style.css` | Dodatkowe style strony i nawigacji. |

## Uruchomienie

Nie jest potrzebna instalacja zależności ani kompilacja. Otwórz plik `index.html` w przeglądarce. Bootstrap jest dołączony lokalnie, dlatego w repozytorium muszą znaleźć się również pliki `css/bootstrap.min.css` i `js/bootstrap.bundle.min.js`.

## Technologie

- HTML
- CSS
- Bootstrap 5.0.2
- JavaScript (Bootstrap Bundle)

# Bootstrap 5 Exercises

[Wersja polska powyżej](#%C4%87wiczenia-bootstrap-5)

A set of HTML, CSS, and Bootstrap 5 exercises. The page features a responsive photo gallery, a navigation bar with a dropdown menu, category switches, and a sample form.

## Repository overview

The project contains a single HTML page built with a local copy of Bootstrap 5.0.2. The gallery layout adapts to the screen width, and the navigation collapses on smaller screens. The navigation bar and form are based on tasks from the Polish INF.04 vocational exams. The page also includes a search form and category switches. These are interface examples and are not connected to application logic.

## Exercises

| File | Description |
| --- | --- |
| `index.html` | A responsive 12-image gallery, dropdown navigation, a search form, category switches, and a sample form. |
| `style.css` | Additional page and navigation styles. |

## Getting started

No dependency installation or build step is required. Open `index.html` in a web browser. Bootstrap is included locally, so the repository must also contain `css/bootstrap.min.css` and `js/bootstrap.bundle.min.js`.

## Technologies

- HTML
- CSS
- Bootstrap 5.0.2
- JavaScript (Bootstrap Bundle)
